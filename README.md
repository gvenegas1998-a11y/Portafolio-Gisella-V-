# Portafolio Web — Gisella Venegas Peralta

Sitio web personal y portafolio interactivo desarrollado para exhibir proyectos de diseño gráfico, desarrollo front-end, packaging, branding y marketing digital. Diseñado bajo una estética editorial y orgánica, con soporte completo para modo claro/oscuro y enfoque en accesibilidad web (A11y).

🔗 **Demo en vivo:** [https://gvenegas1998-a11y.github.io/Portafolio-Gisella-V-/](https://gvenegas1998-a11y.github.io/Portafolio-Gisella-V-/)

---

## 🌿 Características Principales

- **Diseño Editorial & Paleta Orgánica:** Tipografía cuidada (Playfair Display, Plus Jakarta Sans y acentos en Alex Brush) con colores tierra, salvia y lino cálido.
- **Modo Claro / Oscuro Nativo:** Alternador de tema dinámico con persistencia mediante `localStorage` y compatibilidad con `data-bs-theme` de Bootstrap 5.3.3.
- **Diseño Responsivo:** Adaptado fluidamente a dispositivos móviles, tablets y pantallas de escritorio.
- **Accesibilidad & Código Semántico:** Estructura pensada para lectores de pantalla y navegación asistida (estándares A11y).
- **Formulario de Contacto Funcional:** Validación interactiva en tiempo real con JavaScript e integración con FormSubmit para recepción directa de mensajes por correo.
- **Menú Móvil Inteligente:** Cierre automático del menú desplegable al hacer clic en cualquier enlace de sección.

---

## 🛠️ Tecnologías & Herramientas

- **Estructura:** HTML5 semántico
- **Estilos:** CSS3 personalizado, Variables CSS nativas (Custom Properties)
- **Framework UI:** Bootstrap 5.3.3
- **Lógica e Interactividad:** JavaScript moderno (ES6+)
- **Iconografía:** Font Awesome 6.5.1
- **Tipografías:** Google Fonts
- **Despliegue:** GitHub Pages

## 📁 Proyectos Destacados Incluidos

1. **Alke Wallet:** Billetera digital orientada a transacciones seguras con altos estándares de accesibilidad digital y marcado semántico.
